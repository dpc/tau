# DECISION-tau-cli-bundled-component-vocabulary: Bundled component vocabulary

Authority: confirmed, 2026-06-17, dpc

The unified binary uses `tau component <component>` for the harness and bundled
extensions. The vocabulary is deliberately broader than “extension”; `tau ext` is
not a compatibility alias. One command family keeps internal launch configuration
consistent across components without incorrectly classifying the harness.
