# DECISION-tau-cli-conservative-default-theme: Conservative default theme

Authority: confirmed, 2026-06-17, dpc

Tau defaults to terminal-palette-safe `tau-plain-dark`, retaining semantic text
attributes while using only conservative terminal colors. More opinionated and
light-background themes remain selectable rather than becoming the default. This
trades some visual distinctiveness for readability across unusual terminal palettes;
exact styles belong to the theme definitions.
