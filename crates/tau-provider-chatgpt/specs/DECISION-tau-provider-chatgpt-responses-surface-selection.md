# DECISION-tau-provider-chatgpt-responses-surface-selection: GPT-5.6 Responses surface selection

Authority: confirmed, 2026-07-14, dpc

GPT-5.6 Sol, Terra, and Luna use standard ChatGPT/Codex Responses by default.
Responses Lite is an explicit per-profile compatibility mode and is never inferred
from model names, catalog hints, retries, or fallback because Tau does not implement
Lite's programmatic code-mode tool-call workflow.

Changing the default requires a replacement human-approved decision after the
required tool workflow and agent capability/efficiency tradeoffs are evaluated.
