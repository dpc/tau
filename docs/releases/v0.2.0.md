# Tau v0.2.0

## Highlights

- **Native Grok support:** device authorization, model discovery, isolated OAuth
  credentials and refresh, streamed Responses inference, and native opaque
  compaction. One account's live trial accepted initial compaction and
  recompaction; this is not a guarantee of entitlement across accounts,
  semantic fidelity, or restart recovery with live provider state.
- **Project context follows workdir changes:** committed shell workdir changes
  refresh agent project instructions and skill discovery before continuing.
  Scoped skill discovery retains candidates and respects role visibility.
- **Configurable idle shutdown:** `session_idle_shutdown` lets inactive sessions
  stop automatically. It is disabled by default; releasing Tau does not change
  an existing user's configuration or restart their services.
- **Coordination and observability:** sticky automatic bridge receivers,
  clearer live agent status and completion statistics, content-free performance
  offsets anchored to UTC, and bounded Codex response-side cache diagnostics.
- **Artifacts and tools:** large text pastes can use shared artifacts; canonical
  artifact references work across supported tools. Shell grep runs in-process
  with ripgrep libraries. Papercut history tools require explicit role grants.
- **CLI and guidance:** Ctrl-H/Ctrl-L agent navigation defaults, expanded built-in
  self-knowledge for coordination, context and cache evidence, trust boundaries,
  session operation and extension integration, plus reliability fixes across
  compaction, cancellation, persistence and provider handling.

## Compatibility

This release uses harness protocol **10.1** and Rust SDK
`dpc-tau-proto` / `dpc-tau-client` **0.9.0**. The SDK minor version reflects public
Rust source changes; it is not the application or wire protocol version.
The seven packaged external extension projects use SDK **0.8.0** / protocol
**10.0**. Same-major skew is admitted with a visible warning and best-effort
operation; their normal functionality does not require the optional 10.1
papercut-history operations. Older protocol-major extensions must be rebuilt.

Tau remains pre-1.0. Do not assume journal compatibility with v0.1.1; back up
state and finish important work before an intentional upgrade. This release
does not activate Nix configuration, replace running binaries, or restart
existing sessions automatically.

## Distribution

The verified native release includes Linux **amd64 and arm64**, with DEB, RPM
and tar.gz packages for Tau, seven external extension projects, and the Telegram
gateway. `tau-full` DEB/RPM is an exact-dependency metapackage; its tarball bundles
the payloads. External packages retain their upstream Cargo versions and carry
a Tau release-set revision.

The native build checks ELF dependencies, archive contents, licenses, manifests
and checksums. Those checks are not distro installation, CPU/kernel,
service-lifecycle or provider-account qualification. The package dependency
floor remains glibc 2.34; no additional platform support is claimed.

All 31 new crate versions are published on crates.io; the complete 34-package
closure was verified, including three unchanged dependencies. A fresh registry-only
SDK consumer and isolated locked Tau installation passed. The release contains
67 verified assets: 30 packages/archives and three metadata files per architecture,
plus aggregate `SHA256SUMS`. All downloaded assets matched their published sizes
and SHA-256 digests; source, toolchain, dependency and license manifests were
verified against the tagged source. Native build checks do not replace the runtime
qualification limits above.
